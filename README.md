
## 📌 Overview
StackSync is a full-stack web application built using **Spring Boot (backend)** and **React (frontend)**.  
It demonstrates REST API development, frontend-backend integration, and asynchronous data handling using modern JavaScript techniques like Fetch and Axios.

---

## 🛠️ Tech Stack

### Backend
- Java
- Spring Boot
- Spring Web
- Spring Data JPA
- Hibernate
- MySQL / H2 Database

### Frontend
- React
- JavaScript (ES6+)
- Fetch API
- Axios

## ⚙️ Features

- RESTful API using Spring Boot  
- CRUD operations  
- React frontend integration  
- API calls using:
  - Fetch (then/catch)
  - Fetch (async/await)
  - Axios (then/catch)
  - Axios (async/await)
- Error handling implemented  
- JSON-based data exchange  

---

## 🔗 Application Flow

1. User interacts with the React UI  
2. React sends API request to backend  
3. Spring Boot processes request  
4. Database operations are performed  
5. JSON response is returned  
6. UI updates dynamically
